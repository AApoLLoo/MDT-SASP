Mentions légales & confidentialité

Ce que ce site collecte, pourquoi, et comment le faire supprimer.

Éditeur

Ce site est édité par la San Andreas State Police, Département de la Sécurité publique de l'État de San Andreas.

Responsable de la publication : le commandement de la SASP. Contact : formulaire de contact.

Hébergeur : [nom, adresse et contact de l'hébergeur à compléter].

Données collectées

Le site ne dépose aucun cookie publicitaire ni de mesure d'audience. Seuls l'espace agent et l'administration utilisent un cookie de session, strictement nécessaire à la connexion. Votre choix de thème clair ou sombre est mémorisé dans votre navigateur ; il n'est jamais envoyé au site.

Toutes les ressources du site (polices, images, scripts) sont servies par le site lui-même : votre navigateur ne contacte aucun service tiers.

Lorsque vous contactez la SASP, nous enregistrons :

  • vos nom et prénom et, si vous le donnez, un moyen de vous joindre ;
  • le type de demande, l'objet et vos messages ;
  • les dates d'envoi.

Votre code de suivi n'est pas conservé en clair : seule une empreinte chiffrée est enregistrée. C'est pourquoi il ne peut pas vous être renvoyé.

Lorsque vous envoyez une candidature, nous enregistrons :

  • votre pseudo Discord, pour vous recontacter ;
  • l'identité de votre personnage : nom, date de naissance, téléphone, nationalité, casier judiciaire (informations de jeu, fictives) ;
  • le service souhaité, vos disponibilités, vos objectifs, votre parcours et vos réponses de motivation ;
  • la date d'envoi.

Votre adresse IP est utilisée temporairement, en mémoire, pour limiter les envois abusifs. Elle n'est pas enregistrée.

Utilisation et conservation

Les demandes sont lues uniquement par les agents de la SASP connectés avec leur matricule. Les candidatures sont consultées par le commandement.

Chaque nouvel envoi est signalé sur le serveur Discord de la SASP, hébergé par Discord Inc. (États-Unis). Ce message contient, pour une candidature : le nom et la date de naissance du personnage, votre pseudo Discord, le service souhaité, votre objectif et votre réponse « Pourquoi vous » ; pour une demande : son objet, le nom indiqué et le rendez-vous souhaité. Ces messages suivent les règles de conservation de Discord et peuvent être supprimés sur demande.

Les demandes clôturées et les candidatures traitées sont supprimées automatiquement 6 mois après leur clôture ou la décision.

Vos droits

Vous pouvez demander à consulter, corriger ou supprimer vos données à tout moment via le formulaire de contact, en indiquant votre code de suivi si vous en avez un.
